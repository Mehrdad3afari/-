# ریتم | برنامه هفتگی من

یک وب‌اپ فارسی و راست‌چین برای مدیریت برنامه‌ی دانشگاه، کار و فعالیت‌های شخصی. برنامه‌ی هفتگی نمونه براساس زمان‌بندی‌ای است که کاربر ارائه کرده است.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای اجرای ساده نیازی به نصب یا ساخت ندارد.

## امکانات

- نمایش برنامه‌ی ساعت‌به‌ساعت از شنبه تا جمعه؛ در موبایل با انتخاب روز و فهرست خوانای فعالیت‌ها
- ثبت برنامه‌ی هفتگی فرستاده‌شده، شامل چهار جلسه باشگاه، دانشگاه، کار، یادگیری و برنامه‌های شخصی
- افزودن، ویرایش و حذف فعالیت با انتخاب روز، دسته و ساعت
- فهرست ریزفعالیت‌های جداگانه برای هر روز، با ساعت اختیاری و تیک انجام‌شدن
- نوار پیشرفت روزانه بر اساس تعداد کارهای انجام‌شده
- تیک‌زدن فعالیت‌های زمان‌بندی‌شده از چک‌لیست و نسخه‌ی موبایل
- مشخص کردن تداخل زمانی
- ذخیره‌ی برنامه و تیک‌ها در حافظه‌ی مرورگر
- نمایش سازگار با موبایل و رایانه

## انتشار با GitHub Pages

فایل‌های این پوشه را در یک مخزن جدید GitHub قرار دهید و در **Settings → Pages**، منبع انتشار را روی **GitHub Actions** بگذارید. گردش‌کار داخل `.github/workflows/deploy.yml` با هر بار به‌روزرسانی شاخه‌ی `main` سایت را منتشر می‌کند. این نسخه داده‌ها را فقط در مرورگر همان دستگاه نگه می‌دارد.
